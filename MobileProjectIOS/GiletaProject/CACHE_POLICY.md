# Политика кэширования новостей и изображений

## Что кэшируем
- **Список новостей**: JSON-файл `latest_news.json` в `Caches/NewsCache`.
- **Изображения новостей**:
  - бинарные файлы в `Caches/ImageCache`;
  - метаданные (url, имя файла, срок жизни, последний доступ, размер) — в SQLite базе `metadata.sqlite`.

## Почему именно так

### Новости
Новости приходят списком и полностью заменяются при каждом обновлении, поэтому для них достаточно **файлового кэша**:
- чтение дешёвое и быстрое;
- не нужен сложный поиск по отдельным записям;
- JSON удобно сериализовать и отлаживать.

### Изображения
Изображений много, они весят больше и имеют разный срок жизни, поэтому нужен **двухуровневый кэш**:
- `NSCache` в памяти — для быстрого повторного показа без чтения с диска;
- файловая система — для сохранения между запусками приложения;
- SQLite — чтобы хранить метаданные и чистить кэш по сроку жизни и размеру, не сканируя папку вслепую.

## Политика для новостей
- **freshness TTL = 15 минут**: если кэш моложе 15 минут, он считается свежим и может быть показан сразу.
- **max retention = 24 часа**: кэш старше суток удаляется автоматически.
- При открытии экрана:
  1. сначала показывается кэш, если он есть;
  2. затем выполняется запрос в сеть;
  3. при успехе UI обновляется свежими данными и кэш перезаписывается;
  4. при ошибке сети пользователь остаётся на сохранённых данных.

Такой подход даёт быстрый первый экран и не блокирует UI даже при медленной сети.

## Политика для изображений
- память (`NSCache`) используется для повторных показов внутри текущей сессии;
- диск хранит изображения до **7 дней**;
- общий размер дискового кэша ограничен **100 МБ**;
- при превышении лимита удаляются **самые давно не использованные** изображения;
- если запись в SQLite есть, а файла уже нет, метаданные удаляются автоматически.

## Когда происходит очистка
- для новостей:
  - при старте экрана новостей;
  - при чтении кэша;
  - если кэшу больше 24 часов, файл удаляется.
- для изображений:
  - при инициализации кэша;
  - после сохранения нового изображения;
  - удаляются протухшие и самые старые записи при выходе за лимит размера.

## Где скрыта работа с сетью и кэшем
- `NYTNewsService` — только сеть;
- `FileNewsCacheStorage` — только локальный кэш новостей;
- `CachedNewsRepository` — объединяет сеть и кэш, наружу отдаёт готовые данные;
- `ImageLoader` + `PersistentImageCache` + `ImageMetadataStore` — загрузка и кэширование изображений.

Это разделение упрощает поддержку, тестирование и соблюдает требование задания про отдельные сервисы/репозитории.
